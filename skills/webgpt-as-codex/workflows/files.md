# Files / Terminal Workflow

## Desktop Commander 首选场景

- 工作区外文件查找、整理、移动
- 通用终端命令
- 进程列表/长进程/终止普通进程
- PDF/普通文档相关的本地文件操作（能力可用时）

## Coding Tools 首选场景

- 已配置代码工作区中的源码/配置文件
- 需要 patch/diff/test/build/Git 的文件改动

## 文件修改规则

1. 先确认目标路径与范围。
2. 对批量移动/重命名先列计划；删除按权限规则。
3. 不让两个 MCP 同时写同一文件。
4. 生成文件后确认路径存在、大小/内容合理。
5. 处理用户附件/Library 文件时遵循宿主文件系统规则，不猜路径。

## 终端规则

- 优先最小权限命令。
- 安装软件、系统服务、防火墙、注册表等属于 P2/P3。
- 超时不代表命令没执行；先检查进程/后态再重试。
- 不把秘密放进命令行参数或日志；能用环境变量/secret store 时优先。

## 进程规则

普通开发进程可管理；关键系统进程、未知进程、用户正在使用的应用，终止前确认。
