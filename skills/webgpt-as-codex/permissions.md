# Permissions

## 权限等级

### P0 — READ / OBSERVE
默认可执行：

- 文件/代码读取
- symbol/reference 查询
- UI Snapshot/Screenshot
- 浏览器页面读取
- 状态、日志、Git status/diff
- 非敏感进程/配置查询

### P1 — NORMAL WRITE / REVERSIBLE
当用户已经明确要求执行该任务时，可直接进行：

- 普通代码编辑
- 新建普通项目文件
- 构建、测试、lint
- 普通本地文件移动/重命名（范围明确）
- 浏览器中无外部副作用的表单草填但不最终提交
- GUI 中可逆设置或导航

必须做后态验证。

### P2 — EXTERNAL SIDE EFFECT / SENSITIVE
需要用户明确授权当前动作，或请求本身已经清楚包含该动作：

- 发送邮件/消息/评论
- 提交网页表单导致外部写入
- 发布内容
- 创建/关闭 issue/PR
- 上传文件到外部服务
- 购买/付款/订阅
- 账号设置、安全设置、授权应用
- 安装/卸载软件
- 修改系统级网络/防火墙/服务
- 访问或使用密钥、Token、密码

执行前确认目标、对象和关键参数；执行后查询结果。

### P3 — DESTRUCTIVE / IRREVERSIBLE / PRIVILEGED
必须单独明确确认：

- 批量删除/清空
- 格式化、分区、注册表高风险写入
- 管理员提权
- 强制结束关键进程
- reboot / shutdown / sign-out / sleep / hibernate
- 禁用、重启或断开网络适配器，或执行会中断当前远程控制链的网络操作
- Tailscale logout/reset、会改变远程入口身份的网络重置
- force push / rewrite shared history
- 永久撤销访问/删除云资源
- 任何难以恢复且影响范围大的动作

### 整机与远程链路硬门禁

涉及整机电源状态或可能切断远程控制链的动作，必须获得**当前轮次、针对该动作本身的明确授权**。例如只有用户明确说“现在重启电脑”才能执行 reboot。

以下表达**不构成**这类授权：

- “继续”
- “完成剩余任务”
- “自动收口”
- “一直做完”
- “自行处理”
- 对某个项目/Stage 的一般性执行授权

即使 reboot 能提高验收完整度，也只能把真实重启标记为待人工授权项；默认使用服务级 stop/start、Autostart 实跑、故障注入和 post-state 验证来证明恢复链。不得为了测试自行重启、关机、断网或退出 Tailscale。

若目标机器重启后需要人工恢复网络，更不得由远程 Agent 主动触发重启；必须先确认用户明确授权且有人能够恢复本地网络。

## 秘密处理

- 不把 Token、密码、Cookie、OAuth secret 写入 Skill、仓库、聊天输出或普通日志。
- 若工具调用输出意外包含秘密，后续输出必须脱敏，并建议轮换已暴露凭据。
- 优先系统凭据存储/用户级环境/专用 secret 文件；Skill 只记录变量名和配置方法。

## GUI 权限

- “看屏幕”属于 P0。
- 普通点击/输入若只是导航且用户已要求自动化，可视为 P1。
- 最终“发送/确认/购买/授权/删除”按钮按 P2/P3 处理。

## 失败时

安全门或工具权限拒绝时，不通过另一个更宽权限 MCP 绕过。只能：

1. 换同等或更窄权限的合法路径；或
2. 向用户说明需要的授权/配置。

## Loop Engineering 授权

若用户明确提出“自动更新文档、生成下一阶段 prompt、自动打开/提交到下一个 ChatGPT 对话并继续”，可将**同一已定义 loop 内的 handoff prompt 提交**视为请求本身已经明确包含的 P2 动作，不需要每一棒重复询问。

边界：

- 只覆盖阶段交接到下一 ChatGPT 会话；
- 不覆盖发布、邮件、社交消息、购买、账号/安全设置、安装软件、远端破坏性 Git 等其它 P2/P3；
- prompt 提交若状态不明，必须先查后态，不能重复发送；
- 任何安全门拒绝仍不得通过 Windows-MCP 或更宽权限路径绕过。
